# SEC-004 Remediation Evidence

## Finding
Password-bearing credential entities returned by API

## Original Severity
High

## CWE
CWE-200 — Exposure of Sensitive Information

## OWASP
A01:2021 — Broken Access Control

## Original Location
J-Test/Controllers/AuthController.cs

## Original Vulnerability
GET /api/Auth/credentials returned Credential database entities directly.

The Credential entity contains the password property.

After SEC-002, this property contains a password hash. Password hashes are
sensitive authentication material and must not be returned to clients.

## Agent Remediation
Changed the credentials query to explicitly project only non-sensitive fields:

- id
- email

The password property is no longer serialized in the API response.

## Files Changed
- J-Test/Controllers/AuthController.cs

## Validation
- dotnet build
- GET /api/Auth/credentials functional test
- verified response contains id and email
- verified response does not contain password
- source scan for the previous direct entity-return pattern

## Functional Impact
The credentials endpoint continues to return credential identification
information required by the client.

Sensitive password data is no longer returned.

## Status
CLOSED
