# SEC-003 — Missing Authentication and Authorization

## Severity
High

## Classification
- CWE-306: Missing Authentication for Critical Function
- CWE-862: Missing Authorization
- OWASP Top 10: A01:2021 — Broken Access Control

## Original Issue
Sensitive backend endpoints were accessible without effective
authentication or authorization enforcement.

## Remediation
Implemented JWT Bearer authentication in the ASP.NET Core backend.

The remediation includes:

- JWT Bearer authentication configured in Program.cs.
- JWT signing key loaded from configuration/User Secrets.
- JWT issuer, audience, lifetime and signing key validation enabled.
- Authentication middleware added before authorization middleware.
- Sensitive controllers/endpoints protected using [Authorize].
- Signup and Login explicitly exposed using [AllowAnonymous].
- Login generates a time-limited JWT after successful authentication.
- React stores the JWT in sessionStorage.
- React sends the JWT using the Authorization: Bearer header.
- Logout removes the JWT from sessionStorage.
- React restores authentication state from sessionStorage after page refresh.

## Verification

### Positive Test
1. Logged in using valid application credentials.
2. JWT was returned by the backend.
3. JWT was stored in sessionStorage.
4. Protected API requests contained an Authorization: Bearer header.
5. Settings, Jira import and test-case generation continued to function.
6. Page refresh retained the authenticated session.

Result: PASS

### Negative Test
Protected APIs were called without a JWT.

Expected result:
HTTP 401 Unauthorized

Actual result:
HTTP 401 Unauthorized

Result: PASS

### Logout Test
Logged out from the application and verified that authToken was removed
from sessionStorage.

Result: PASS

## Functional Regression
Existing login, Settings, Jira import and test-case generation functionality
was tested after the remediation.

Result: PASS
