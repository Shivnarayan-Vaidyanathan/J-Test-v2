# SEC-014 — Vulnerable / Outdated Dependencies

## Severity
High

## Classification
- CWE-1104: Use of Unmaintained Third-Party Components
- OWASP Top 10: A06:2021 — Vulnerable and Outdated Components

## Original Issue
The application contained vulnerable and outdated third-party dependencies
across both the ASP.NET Core backend and React frontend.

The dependency review identified:

- `Jira.SDK 1.2.25` in the backend.
- `Jira.SDK` introduced the vulnerable transitive dependency
  `RestSharp 105.2.3`.
- `RestSharp 105.2.3` was reported as a High-severity vulnerable package.
- `Jira.SDK` and `RestSharp` were restored against older .NET Framework
  targets instead of the application's `net8.0` target, producing NU1701
  compatibility warnings.
- The frontend dependency tree reported 33 vulnerabilities:
  18 High, 6 Moderate and 9 Low.
- A large portion of the frontend High-severity findings originated from the
  deprecated `react-scripts` / Create React App toolchain.
- The frontend also contained a separate Moderate vulnerability through
  `html-docx-js` → `jszip`.

## Remediation

### Backend Dependency Remediation
A source-code usage review confirmed that `Jira.SDK` was not used by the
application.

The Jira integration already uses `HttpClient`,
`HttpRequestMessage` and `AuthenticationHeaderValue`, so the unused
`Jira.SDK` dependency was removed.

The remediation included:

- Removed `Jira.SDK 1.2.25`.
- Removed the transitive `RestSharp 105.2.3` dependency.
- Removed the High-severity RestSharp advisory from the backend dependency
  graph.
- Removed the Jira.SDK / RestSharp NU1701 compatibility warnings.
- Retained the existing `HttpClient`-based Jira integration.
- Rebuilt and rescanned the backend after removal.

### Frontend Dependency Remediation
The frontend was migrated away from the deprecated Create React App
`react-scripts` build toolchain.

The remediation included:

- Removed `react-scripts`.
- Installed Vite as the frontend build tool.
- Installed `@vitejs/plugin-react`.
- Added `vite.config.mjs`.
- Retained port `3000` to preserve the existing ASP.NET Core CORS
  configuration.
- Added a root-level Vite `index.html`.
- Removed CRA-specific `%PUBLIC_URL%` usage.
- Removed `reportWebVitals` from the application entry point.
- Removed the unused `reportWebVitals.js` file.
- Renamed React source files containing JSX from `.js` to `.jsx`.
- Updated `package.json` scripts to use Vite for start, development, build
  and preview operations.
- Preserved existing Login, Settings, Jira, Gemini, DOMPurify, export and
  logout functionality during migration.

The CRA-related vulnerable dependency chains were removed together with
`react-scripts`, including findings involving:

- `node-forge`
- `nth-check`
- `postcss`
- `serialize-javascript`
- `webpack-dev-middleware`
- other deprecated Create React App transitive packages

## Verification

### Backend Vulnerability Scan
The following command was executed:

```powershell
dotnet list package --vulnerable --include-transitive
```

Actual result:

```text
The given project `J-Test` has no vulnerable packages given the current sources.
```

Result: PASS

### Backend Vulnerable Package Removal Check
The following command was executed:

```powershell
dotnet list package --include-transitive |
    Select-String -Pattern 'Jira.SDK|RestSharp'
```

Actual result:
No matches were returned.

This confirms that both `Jira.SDK` and `RestSharp` were removed from the
backend dependency graph.

Result: PASS

### Backend Build
The backend was rebuilt after dependency removal.

Expected result:
Build succeeds without the previous Jira.SDK / RestSharp compatibility
warnings.

Actual result:
Backend build completed successfully.

Result: PASS

### Frontend Baseline Vulnerability Scan
The frontend baseline scan was executed using:

```powershell
npm audit
```

and:

```powershell
npm audit --omit=dev
```

Baseline result:

```text
33 vulnerabilities
9 low
6 moderate
18 high
```

The audit showed that many High-severity findings were inherited through the
`react-scripts` / Create React App dependency tree.

Result: BASELINE CAPTURED

### Frontend Build-System Migration
The frontend build system was migrated from Create React App to Vite.

Verified changes include:

- `react-scripts` removed.
- Vite installed.
- React Vite plugin installed.
- Vite entry HTML created at the project root.
- CRA-specific entry configuration removed.
- React files containing JSX migrated to `.jsx`.
- Vite build scripts configured.

Result: PASS

### Final Frontend Vulnerability Re-scan
After the Vite migration, the frontend dependency scan was rerun using:

```powershell
npm audit
npm audit --omit=dev
```

The previous High-severity vulnerabilities inherited through
`react-scripts` were confirmed removed.

Any remaining Moderate/Low findings were reviewed separately and did not
block closure of the High-severity dependency remediation.

Result: PASS

### Frontend Production Build
The following command was executed after the Vite migration:

```powershell
npm run build
```

Expected result:
The production frontend build completes successfully using Vite.

Actual result:
The production frontend build completed successfully.

Result: PASS
