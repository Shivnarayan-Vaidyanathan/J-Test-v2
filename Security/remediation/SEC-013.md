# SEC-013 — Swagger Exposed in All Environments

## Severity
Medium

## Classification
- CWE-215: Insertion of Sensitive Information Into Debugging Code
- OWASP Top 10: A05:2021 — Security Misconfiguration

## Original Issue
Swagger and Swagger UI were enabled unconditionally in the ASP.NET Core
application.

This meant that API documentation and endpoint metadata could remain
accessible when the application was running in non-development environments
such as Production or Staging.

Exposing Swagger outside Development can unnecessarily reveal:

- API routes and operations.
- Request and response structures.
- Authentication requirements.
- Backend endpoint metadata.
- Internal API surface details useful for reconnaissance.

## Remediation
Restricted Swagger and Swagger UI to the ASP.NET Core Development
environment.

The Swagger middleware is now executed only when:

```csharp
app.Environment.IsDevelopment()
```

The remediation includes:

- Swagger middleware remains available for local development.
- Swagger UI remains available for developer testing.
- Swagger JSON remains available in Development.
- Swagger middleware is not registered in Production.
- Swagger middleware is not registered in Staging.
- Existing API controllers and authentication behavior remain unchanged.

The resulting implementation follows this pattern:

```csharp
if (app.Environment.IsDevelopment())
{
    app.UseSwagger();

    app.UseSwaggerUI(options =>
    {
        options.SwaggerEndpoint(
            "/swagger/v1/swagger.json",
            "User Story API V1");

        options.RoutePrefix = string.Empty;
    });
}
```

## Verification

### Development Environment Test
The backend was started using:

```powershell
$env:ASPNETCORE_ENVIRONMENT="Development"
dotnet run
```

Expected result:
Swagger UI loads successfully in the Development environment.

Actual result:
Swagger UI loaded successfully.

The Swagger JSON endpoint was also available at:

```text
/swagger/v1/swagger.json
```

Result: PASS

### Production Environment Test
The backend was started using:

```powershell
$env:ASPNETCORE_ENVIRONMENT="Production"
dotnet run
```

Expected result:
Swagger UI and Swagger JSON are not exposed in the Production environment.

Actual result:
Swagger UI was not available and the Swagger JSON endpoint was not exposed
through Swagger middleware.

Result: PASS

### Production API Regression Test
A normal application API flow was tested while the backend was running in
the Production environment.

Expected result:
Normal API functionality continues to work while Swagger remains disabled.

Actual result:
Application API functionality continued to work and Swagger remained
unavailable.

Result: PASS

## Functional Regression
Existing backend functionality was tested after restricting Swagger to the
Development environment.

Verified that:

- Development Swagger access continued to work.
- Production Swagger access was blocked.
- Protected API endpoints continued to function.
- Authentication behavior remained unchanged.
- Existing frontend-to-backend communication remained functional.

Result: PASS

CLOSED
